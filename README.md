# Kitap ve Film Takip Uygulaması 

Bu proje C# dili kullanılarak geliştirilmiş, nesne yönelimli programlama (OOP) prensiplerini ve esnek arama algoritmalarını barındıran bir Konsol Takip Uygulamasıdır
Kullanıcıların okudukları/okuyacakları kitapları ve izledikleri/izleyecekleri filmleri tek bir kütüphane altında yönetmelerini, kayıtları yerel hafızada kalıcı olarak saklamalarını sağlar.

Öne Çıkan Özellikler (CRUD):
Ekleme, Listeleme, Güncelleme, Esnek arama, Silme, Tümünü silme, Kalıcı veri yönetimi (Json)

Kullanılan OOP prensipleri:
Kalıtım, Polimorfizm, Soyutlama

Projede LINQ kullanılmıştır.
